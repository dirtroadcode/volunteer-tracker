# Copy-based distribution

Coordinator campaigns are created by copying the Sample Spreadsheet — the
bound script and all tabs travel with the copy, and each copy installs its
own triggers (and links its own Form, Sample or BYO) through a single
"Set Up" menu action that runs once. Calendar events always land
on the copy's default calendar, so every coordinator automatically gets their
own isolated calendar. We rejected copying the Form first (a Form copy's
response sheet arrives with no script on it) and rejected any per-campaign
hosting or dedicated app — the whole product is "one copy away from running."
